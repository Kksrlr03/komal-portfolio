Featured Projects

🛒 ProdLoca — Discover Products in Nearby Local Stores

Problem
Finding products across nearby local stores is often inefficient, requiring users to visit multiple shops or rely on large e-commerce platforms that may not reflect local availability.

Solution
Developed ProdLoca, a location-aware web application that helps users discover products available in nearby local businesses through an intuitive and map-based interface.

What I Learned
This project strengthened my understanding of user-centric design, geolocation services, real-time databases, frontend development, and building applications focused on solving practical everyday problems.

Technology Stack
React • Firebase Realtime Database • Mapbox GL

Solution
